About SmartEdge

Predictive Edge Caching for a Smarter CDN

SmartEdge is an ML-driven predictive edge caching system that uses a Random Forest classifier to make intelligent cache admission decisions. Unlike traditional LRU and LFU algorithms, SmartEdge predicts content reuse probability before caching, resulting in significantly higher hit rates.

Architecture

  • Backend: FastAPI with scikit-learn Random Forest model
  • Cache Engine: Score-based eviction with ML admission threshold
  • AI Agent: RAG-powered analyst using Ollama LLM
  • Dataset: NASA web server access logs

Key Features

  • Real-time cache hit/miss tracking with live statistics
  • ML prediction engine for cache admission decisions
  • Offline benchmark comparison (LRU vs LFU vs SmartEdge)
  • AI-powered performance analysis and optimization suggestions
